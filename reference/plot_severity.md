# Plot Burn severity

Plot Burn severity

## Usage

``` r
plot_severity(
  x,
  title = "Burn severity",
  subtitle = NULL,
  caption = NULL,
  boundary = NULL
)
```

## Arguments

- x:

  A single-layer dNBR SpatRaster.

- title:

  Plot title.

- subtitle:

  Plot subtitle

- caption:

  Optional plot caption

- boundary:

  Optional boundary to overlay on the plot.

## Value

A ggplot object.
