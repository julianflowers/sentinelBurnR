# Calculates Normalized Differences

Calculates Normalized Differences

## Usage

``` r
.normalised_difference(x, numerator, denominator, name)
```

## Arguments

- x:

  A `SpatRaster` containing `band1` and `band2`.

- numerator:

  Name of the numerator band.

- denominator:

  Name of the denominator band.

- name:

  Name of the output layer.

## Value

A single-layer `SpatRaster` named `ndvi`.
