# Calculate relative humidity and vapour pressure deficit

Calculate relative humidity and vapour pressure deficit

## Usage

``` r
calc_humidity(temperature_c, dewpoint_c)
```

## Arguments

- temperature_c:

  Air temperature in degrees Celsius.

- dewpoint_c:

  Dew-point temperature in degrees Celsius.

## Value

A data frame containing `relative_humidity` in percent and `vpd_kpa` in
kPa.
