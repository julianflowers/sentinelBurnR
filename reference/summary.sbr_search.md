# Summarise a Sentinel-2 search

Returns scene-level metadata from a Sentinel-2 catalogue search.

## Usage

``` r
# S3 method for class 'sbr_search'
summary(object, ...)
```

## Arguments

- object:

  An `sbr_search` object.

- ...:

  Additional arguments, currently unused.

## Value

A data frame with one row per Sentinel-2 scene.
