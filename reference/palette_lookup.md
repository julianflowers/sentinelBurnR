# SentinelBurnR colour palette

Returns a colour palette used for SentinelBurnR maps.

## Usage

``` r
palette_lookup(name, n = 256)
```

## Arguments

- name:

  Character. Palette name. One of `"burn"`, `"moisture"`, `"stress"`, or
  `"vegetation"`.

- n:

  Integer. Number of colours to return.

## Value

A character vector of colours.
