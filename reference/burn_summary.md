# Summarise burn statistics

Summarise burn statistics

## Usage

``` r
burn_summary(burn, boundary = NULL, id = NULL)
```

## Arguments

- burn:

  An `sbr_burn` object.

- boundary:

  Optional boundary. If omitted, `burn$boundary` is used.

- id:

  Optional attribute used to name polygons.

## Value

An object of class `sbr_summary`.
