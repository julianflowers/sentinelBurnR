# Build burn provenance

Construct provenance metadata for a burn analysis.

## Usage

``` r
build_provenance(pre, post, threshold, assets)
```

## Arguments

- pre:

  Pre-fire Sentinel-2 collection.

- post:

  Post-fire Sentinel-2 collection.

- threshold:

  Burn detection threshold.

- assets:

  Spectral assets used in the analysis.

## Value

A list containing provenance information.
